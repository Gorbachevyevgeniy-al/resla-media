# AGENTS.md — проект «Instagram SINEP» (@cosmetics.kaz.kz)

Инструкция для любого AI-агента. Состояние на 25.10.2026. Язык общения с владельцем: русский.

## 1. Цель
- Автономный Instagram-аккаунт **@cosmetics.kaz.kz** (тип BUSINESS, IG user id `17841461175377751`).
- Продвижение бренда **SINEP** (Турция, производитель Flowers Cosmetic, Стамбул; сайт https://sinep.com.tr).
- Продажи идут через магазин владельца **RESLA на Kaspi** (merchant 30417336): https://kaspi.kz/shop/info/merchant/30417336/address-tab/
- Владелец: Евгений. Его роль: согласовывает план/пакет контента, дальше всё делает агент. Сам он ничего не выкладывает (исключение: добавить сториз в кружки «Актуального» и правки шапки профиля в приложении).
- Профиль многобрендовый: позже добавятся другие бренды (какие, пока не названо). Сейчас только Sinep.

## 2. Правила проекта (постоянные)
1. Перед новой задачей проверить скилл `find-skills`, есть ли подходящий скилл. Перед установкой показать список и ждать согласия Евгения.
2. Только бесплатные ресурсы. Платные сервисы/скиллы не рассматривать (отклонены: Apify, платные навыки, Canva Pro, Motion API).
3. Качество высокое; визуал должен продавать товар и цеплять внимание.
4. Только проверяемые факты со ссылками на источник. Никаких догадок и выдуманных свойств товара.
5. Ответы Евгению: коротко, по сути, без воды.
6. При упоре в лимит использования: отложить продолжение на время после сброса лимита и продолжить без вопросов.

## 3. Запреты
- **Цены не указывать нигде**: ни на картинках, ни в подписях.
- **Других продавцов Kaspi не упоминать.** Ссылки и призывы ведут только в RESLA. (Название партнёра, которого нельзя упоминать, хранится в памяти проекта; в этот публичный файл не пишется.)
- **ИИ-результат укладки на волосах нельзя** (Закон РК «О рекламе», ст. 7 п. 2: недостоверные сведения о результатах применения). Допустимо: реальные фото причёсок с карточек товаров Kaspi (одобрено Евгением 22.10.2026 для рилсов; волосы крупно, без лица и бороды; мелкие нечёткие кропы не брать).
- Не постить товары, которых нет в RESLA (колонка «Есть в магазине RESLA» = «Да» в каталоге).
- Не писать «в директ»: призыв только «пишите в комментариях / поделитесь в комментариях».
- Не использовать без прямой просьбы Евгения: живые фото и вырезки (`photos/live`, `photos/cutouts`), шаблон «чёрный шёлк» (`templates/black_silk`), розовые обложки от 17.10.
- Не перевыкладывать опубликованный рилс (снижает показы): ошибки исправлять ДО публикации.
- Не менять согласованный план и расписание без «да» Евгения. Предложения аналитики — только предложения.
- Не скачивать на Mac без команды: `om samples build` и озвучку Kokoro.

## 4. Контент
- Аудитория: мужчины, барберы, женщины, покупающие подарок.
- Товары: в RESLA только укладка волос и воротнички для барберов (бритьё/борода нет).
- Подпись: блок RU → разделитель `———` → блок KZ (казахский перевод того же текста). Казахский проверять обратным переводом (Евгений казахский не знает).
- Товарный пост: подробное описание (что это, эффект, текстура, фиксация/блеск, как и на какие волосы наносить, объём, страна) только из описания Kaspi (лист «Описания и фото» каталога) или страницы товара на sinep.com.tr.
- Концовка: «Сделано в Турции. Ищите в магазине RESLA на Kaspi.» / «Түркияда жасалған. Kaspi-дегі RESLA дүкенінен іздеңіз.»
- Тон на «вы». Хэштегов не больше 5.
- Рилсы работают лучше всего (статистика 20–24.10): упор на рилсы. Длина ~12 с (отдельные согласованные рилсы 15–20 с). Минимум текста на экране. Хук в первом кадре, монтаж под бит, быстрые смены банок (лучший досмотр у рилса «Какой ваш?»: 10,5 с из 15).
- Обложка рилса: без затемнения первого кадра; `thumb_offset` задаётся (поле `thumb` в слоте, по умолчанию 1000 мс).
- Музыка: треки Pixabay (Pixabay Content License, без пометки Content ID). Список использованных: `music-sources.txt` в файлах проекта. Собственный сгенерированный бит Евгению не нравится — не использовать.
- Готовые сториз 21.10–1.11.2026 остаются в расписании.
- Сториз: через API выходят без стикеров, опросов и ссылок; видны в основном подписчикам. С 2.11.2026 — 1 сториз в день.
- Вовлекающие посты стоят по субботам 7.11–5.12.2026 (`posts/schedule_engage.json`); пакеты после 2.11 эти субботние слоты не занимают.

## 5. Дизайн
- Утверждённый стиль: **«банка на камне»**: тёмная сцена, банка Sinep на камне, белые надписи RU+KZ, логотип SINEP сверху по центру. Одна карточка, без карусели. Скилл `/sinepcards` (полное описание макета, CSS, сборщики).
- Форматы: пост 1080×1350, сториз 1080×1920, рилс 1080×1920.
- Шрифты карточек: Oswald + Jost (Google Fonts, есть казахские буквы).
- Многотоварные карточки: вырезки банок (rembg birefnet-general) на каменной плите; белая кайма вырезки недопустима.
- Фото банок: галереи sinep.com.tr (`https://sinep.com.tr/assets/products/<id>/gallery/image_00N.jpg`, турецкие надписи убирать) и карточки товаров RESLA на Kaspi (`resources.cdn-kaspi.kz`). Главные фото Kaspi — инфографика с текстом, для карточек плохо.
- Рендер HTML → JPEG: Playwright/Chromium (`NODE_PATH=$(npm root -g) node render_wait.js ...`). После рендера проверить картинку глазами.

## 7. Публикация (полностью через API)
- API: Instagram API with Instagram Login, `https://graph.instagram.com/v23.0`. Facebook-страница не нужна.
- Поток: `POST /{ig}/media` (image_url / video_url + caption) → опрос `status_code` до `FINISHED` → `POST /{ig}/media_publish`. При ошибке 9007 сразу после FINISHED — подождать и повторить.
- Медиа должны лежать по публичной ссылке: этот репозиторий, ссылки вида `https://raw.githubusercontent.com/Gorbachevyevgeniy-al/resla-media/main/<путь>`. Папки: `posts/2026-10`, `posts/m` (рилсы), `posts/x14`, `posts/w2`, `posts/engage`, `posts/catalog`.
- Скрипты (в файлах проекта `/mnt/project-files/posts/`):
  - `publish.py post|story|reel <url> [caption.txt]` — публикация одной единицы.
  - `run_slot.py <id>` — берёт слот из `schedule_*.json`, публикует, пишет строку в лист «Журнал постов» каталога.
  - `run_batch.py <batch>` — пачка слотов из `catalog_batches.json`, пауза 60 с между сториз.
- Формат слота: `{"id","utc","kind":"post|story|reel","url","caption":путь|null,"fmt","code":код Kaspi,"theme","thumb":мс}`.
- Автозапуск: разовые запланированные задачи (триггеры) будят сессию треда, та запускает `run_slot.py <id>`. Создание задач ограничено (~10 подряд, потом пауза ~40 с).
- Статистика: `/mnt/project-files/analytics/ig_daily.py` → снимки `analytics/snapshots/ГГГГ-ММ-ДД.json`.
